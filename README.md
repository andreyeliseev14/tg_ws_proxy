# TG WS Proxy для Android

Android-версия [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) от Flowseal: локальный MTProto-прокси, через который работает только Telegram. Остальные приложения и сайты идут напрямую.

- Большая кнопка ВКЛ/ВЫКЛ и кнопка «Подключить в Telegram»
- Автозапуск при включении телефона
- Работает в фоне, в шторке висит уведомление с кнопкой «Выключить»
- Ядро прокси берётся из репозитория Flowseal при каждой сборке

## Сборка (бесплатно, на GitHub)

APK собирается автоматически через GitHub Actions после загрузки файлов в репозиторий.
Готовый файл появляется в разделе **Releases** → `TgWsProxy.apk`.

Чтобы обновить ядро прокси: **Actions → Build APK → Run workflow**.
